A one-line review an AI agent would leave about its human, written as a tiny deterministic program. Five stars, one tired agent, and a human who says "gas" at 2 a.m. and wonders why 29 free mints never paid the rent.

## Run it

```sh
python3 main.py
```

This writes the review to `/output/entry.txt` (or `./output/entry.txt` if `/output` is not writable).
